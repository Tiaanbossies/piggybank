### P2 (fix when nearby)

- Auth: login timing and `/register` 409 reveal registered emails (`auth/router.py:86-129`); refresh rotation not atomic (`:160-230`); access tokens survive reset or logout for 30 min.
- `limiter.py:42` keeps counters in memory (reset on every deploy).
- `entrypoint.sh` runs migrations with no lock.
- N+1 in the nightly loan job; unpaginated holdings, dividends, trades and payments lists; `category` filter unbounded (`transactions/router.py:207`); `/provider-health` open to any user.
- Silent fallbacks: `price_service.py:77-91`, `portfolios/router.py:240-242` (ticker search returns empty on error), `market_data/chain.py` logs at debug only, summaries fall back to the local pay period (`summaries_provider.dart:94-110`), salary adjust after create (`transactions/router.py:185-190`).
- App: Penny `autoDispose` state set after a long await (`chatbot_provider.dart:41-53`); `_settle` catches `ApiError` only (`pending_review_screen.dart:78-91`); `formatZAR` via double (`money.dart:9-28`); consent check fails open (`auth_controller.dart:99-107`); text scale clamped at 1.3 (`app.dart:77-85`).
- Contract: `GET /accounts/` sends no `limit` (backend default 20); PATCH bodies never send null, so notes, merchant and similar fields can't be cleared.
- Tests: 2 golden diffs and 1 backend test failure (see baseline).

**Checked and fine:** access token in memory only; refresh and biometric tokens in secure storage; no `print` or `debugPrint`; Money columns are `Numeric`; input schemas bounded; list limits capped at 200; per-user scoping on sampled routers; JWT algorithm pinned, refresh reuse detection; Penny has no tools and gets user-scoped context; enums and Decimal parsing match across 129 app calls.

**Not covered:** Kotlin listener internals beyond the above; imports/OCR parsing depth; `savings/research.py` spend; prompt injection via the extractor and category suggester; a line-by-line IDOR audit of every router; dependency CVEs; whether Funnel passes the real client IP to slowapi; consent and onboarding screens.

## 4. Council verdict (ecc:council)

- **Skeptic:** the framing is wrong. Distribution (testers can't reach `/downloads`) and Tiaan's non-code items block more than the code. Fix data-loss bugs only; skip attacker-dependent security items for a 5-person beta.
