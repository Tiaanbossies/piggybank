Fonts for golden tests only (not bundled in the app).

Both were fetched 2026-10-10 from the same fonts.gstatic.com URLs that google_fonts 6.3.3 downloads at runtime, and their SHA-256 hashes were checked against its manifest. They replace the Manrope files used before the visual rework (visual spec §1.5).
